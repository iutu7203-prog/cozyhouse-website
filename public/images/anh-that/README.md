# Thư mục ảnh thật

Bỏ ảnh chụp thực tế vào đúng thư mục con bên dưới. Sau khi thêm ảnh, báo lại (liệt kê tên file hoặc chỉ cần nói "đã thêm ảnh") để cập nhật vào website — ảnh sẽ **thay thế ảnh minh họa** đang dùng tạm cho từng phòng/khu vực tương ứng.

## Quy tắc đặt tên file (quan trọng)

Đặt tên file **trùng với mã phòng** để việc gán ảnh vào đúng phòng được nhanh và chính xác. Ví dụ: `156-ban-cong-1.jpg`.

Ví dụ: sảnh vào, thang máy, hệ thống PCCC/an ninh, hành lang, khu vực gửi xe... Đặt tên mô tả ngắn gọn, ví dụ `thang-may.jpg`, `an-ninh-pccc.jpg`, `sanh-vao.jpg`.

## Yêu cầu kỹ thuật ảnh

- Định dạng: **JPG, PNG hoặc WEBP**.
- Tỉ lệ khung hình đẹp nhất: **4:3** hoặc **16:9** (ảnh ngang), tránh ảnh dọc bị cắt xấu trên các card.
- Kích thước khuyến nghị: chiều rộng tối thiểu **1200px**, dung lượng mỗi ảnh nên dưới **2MB** (ảnh quá nặng làm web tải chậm — có thể nhờ nén trước qua tool như [Squoosh](https://squoosh.app) nếu file gốc quá to).
- Không cần chỉnh sửa/resize thủ công quá kỹ — ảnh gốc từ điện thoại chụp ngang là đủ dùng.

## Cách khác: upload trực tiếp qua trang quản trị

Nếu chỉ có vài ảnh lẻ và muốn cập nhật ngay không cần chờ, có thể vào `/admin` → chọn phòng/chi nhánh cần sửa → mục "Ảnh" → tải ảnh lên trực tiếp, không cần qua thư mục này.
